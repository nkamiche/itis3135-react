# ITIS 3135 React Assignment

React + Vite recreation of the ITIS 3135 course site pages: Home, Introduction, Contract, and About.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

Or manually push the `dist` folder to the `gh-pages` branch.
